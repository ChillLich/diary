# Diary

**Diary** - полнофункциональная платформа для ведения блога, разработанная на **Django**. Проект является масштабируемым веб-приложением с системой пользователей, публикаций и комментирования, управляется из админ-панели. В проекте применены встроенная система аутентификации Django, ORM для работы с моделями и Class-Based Views для оптимизации структуры контроллеров, что соответствует best practices веб-разработки.

## Основные возможности

| Функция | Описание |
|---------|----------|
| **Публикации** | Создание, редактирование, удаление постов с изображениями |
| **Категории** | Организация контента по тематическим разделам |
| **Комментарии** | Система комментирования с возможностью редактирования |
| **Профили** | Персональные страницы пользователей с историей публикаций |
| **Аутентификация** | Регистрация, вход, управление профилем и паролем |
| **Пагинация** | Постраничный вывод (10 записей на страницу) |
| **Отложенные посты** | Публикация по расписанию |
| **Кастомные ошибки** | Страницы 403, 404, 500 |

## Технологический стек

- **Python:** 3.10+
- **Backend:** Django 3.2+
- **Database:** SQLite / PostgreSQL
- **UI:** django-bootstrap5 22.2
- **Images:** Pillow 9.3.0

## Архитектура проекта

```
blogdiary/
├── blog/           # Приложение блога (посты, категории, комментарии)
├── pages/          # Статические страницы (about, rules, errors)
├── core/           # Аутентификация и регистрация пользователей
├── templates/      # HTML-шаблоны
├── static_dev/     # Статические файлы (CSS, JS, images)
└── blogdiary/      # Настройки проекта
```

## Ключевые решения

- **Миксины для повторного использования кода** - `ListPostsMixin`, `PostOwnerCheckMixin`, `CommentMixin`
- **Оптимизация запросов** - `select_related`, `annotate` для подсчёта комментариев
- **Разделение прав доступа** - авторы видят все посты, гости - только опубликованные
- **DRY-принцип** - переиспользование шаблонов для создания/редактирования

## Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/ChillLich/blogdiary.git
cd blogdiary

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt

# Миграции и запуск
python manage.py migrate
python manage.py runserver
```
